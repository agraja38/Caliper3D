# Security

Do not report vulnerabilities with real scan data, credentials or signing assets. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately before disclosing exploit details publicly. This project does not currently promise a response-time SLA.

The foundation has no active listener, live capture or installer. Imported packages are untrusted. Current storage bounds and manifest validation are a foundation, not a full hostile-asset parser. Real transfer must include approved/authenticated peers, encryption, strict quotas, traversal/symlink defenses and staged atomic completion before release.

Never commit access tokens, Apple credentials, certificates, provisioning profiles, private keys or personal scans. If a credential is exposed, revoke it at its issuer and replace it outside the repository. Do not copy it into an issue, log or documentation.
