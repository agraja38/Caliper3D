# Caliper3D v1.0.0

First native foundation/demo release. **Live object scanning and STL export are not implemented yet.**

## Download and install

Download **Caliper3D-1.0.0.dmg** below. Requires macOS 14 or later; includes Apple Silicon and Intel code. Drag Caliper3D into Applications, or install to your user Applications folder:

```sh
curl -fsSL https://github.com/agraja38/Caliper3D/releases/download/v1.0.0/install.sh | /bin/bash
```

The installer checks SHA-256 integrity and the app signature/version, needs no administrator privileges, and refuses to replace an existing installation. Review the script before running it. A SHA-256 file is included for manual verification.

**Signing:** ad-hoc signed, not Developer ID signed or notarized. macOS may block first launch. Review the download and follow [Apple’s normal app-opening guidance](https://support.apple.com/en-ca/guide/mac-help/mh40616/mac) if needed. The installer never disables Gatekeeper or strips quarantine.

## Included

- Native Mac Library, New Scan, Devices, Processing and Settings.
- Local versioned project packages and non-destructive photo import.
- Interactive RealityKit demo viewport and simulated reconstruction.
- iPhone onboarding and demo capture/review/transfer in source.
- Shared Swift packages, service abstractions, privacy documentation and 19 tests.

Choose **Try Demo Project** after opening the Mac app. The DMG includes the Mac app only; build Caliper3D Capture in Xcode to try the companion Simulator flow.
